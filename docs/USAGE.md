# AimFind 使用说明

> App 里也能看：首页与相机页右上角的「?」就是这份说明的页内版（`iPhone/UI/Help/HelpView.swift`）。
> 其中「关于这个包」一节是**实时读描述文件算出来的**，不是写死的文案。

> 用来在驿站/货架前**按取件码找包裹**：把取件通知截图丢进去，App 认出码做成标签，
> 打开相机后同时帮你找这几个码，找到就标出来、镜头自己合焦到那一点。
> 全程离线，不联网，不上传任何图片。

---

## 一、三步上手

1. **导入取件码**：首页点「从截图导入」，在系统相册选择器里多选取件通知截图（一次最多 9 张）。
   App 会读出截图里的完整取件码，变成标签。旁边的小输入框可以手输一个（回车添加），
   写 `2073` 或 `B2-4-2073` 都认。
2. **整理标签**：标签墙里**向左或向右滑动一个标签即可删除**。上限 12 个，退出重开会保留上次那批。
3. **点「打开相机」**：所有标签一起带进取景画面，顶部显示 `已找到/总数`。

首次会弹相机权限；相册选择器本身**不需要**授予相册权限（系统只把你选中的那张交给 App）。

说明只在**右上角「?」**里，不会自动弹出 —— 这是刻意定的：找件时被人拦住看教程很烦，需要时自己点。

## 二、相机页每个东西是什么

| 位置 | 内容 | 含义 |
|---|---|---|
| 左上 × | 关闭 | 回到首页，同时停止相机 |
| 顶部 `找到 1/3` | 进度 | 三个标签里已经确认找到 1 个 |
| 右上 | `识别就绪` / `变焦 2.4×` | 引擎状态与放大倍数；识别引擎全名挪到了「? › 关于这个包」，主界面不放技术黑话 |
| 横向标签条 | 你的取件码 | `✓` 绿 = 已找到；`≈` 黄 = 疑似（差一个字符）；已找到的自动排到后面 |
| 画面绿实线框 | 精确命中 | 已确认那件再加一层淡绿填充、边框更粗 |
| 画面黄虚线框 `≈` | 疑似 | 差一个字符才对上，**要你自己核对** |
| 底部 `已找到` + 大字 + `右上 · 中距` | 最近确认的那一件 | 大字是码，后面是它在画面里的方位与远近（远近是估算） |
| 底部 `疑似，请核对` | 差一个字符才对上 | 别直接信它，自己看一眼包裹上的码 |
| 白色圆圈 | 合焦点 | 手动点过的地方，或 App 自动对准未找到目标的位置 |

## 三、怎么扫得快（这几条比调参数有用）

1. **慢慢平移，别站着不动。** 镜头一直对着同一处，App 读到新码的时机就少；横向缓移最快。
2. **保持 0.5–1.5 米。** 太近（<10cm）主摄物理上合不了焦；太远那 4 位数字读不出像素。
3. **别正对反光膜。** 驿站标签常覆一层亮膜，稍微侧一点角度，比放大更有用。
4. **停半秒等确认。** 一个码要连续 3 帧读到才算"找到"（大约半秒），扫太快会看到框出现又消失。
5. **读不清就双指放大。** 放大后文字像素变多，命中率立刻上升；手动点一下画面可以先强制合焦。
6. **一次别塞太多标签。** 12 个上限是保护你 —— 一屏找 3~4 件最快，再多反而看不过来。

## 四、底部提示语分别是什么意思

- **「对准货架慢慢扫」** —— 画面里一件包裹码都没读到（可能没对准、太远、或糊了）。
- **「已扫到 N 件…」** —— 读到 N 个取件码了，但里面没有你要的；继续扫。
- **「这层 N 件里没有你要的，换一层试试」** —— 同一个区域 2.5 秒没出现新码、且已读到 ≥3 件，
  App 判断这一层基本扫完了。**这是提示你换层，不是错误。**
- **「全部找到」** —— 这批标签都确认了，镜头不再自动移动。

## 五、它现在做不到什么（避免误判）

- **截图里只写裸 4 位数字的通知，不会变成标签。** 导入只收「货架-层-尾号」完整码，
  且要求识别得干净（宁可漏一条也不要放一个错码进列表 —— 错码会让你在货架前白找半天）。
  提示「没找到取件码」时：换一张更清晰/没折行的截图，或手输。
- **前缀对不上就不标。** 你搜 `B2-4-2073`，画面里那件写着 `B2-5-2073`（同尾号不同层）会被**忽略**，
  因为它不是你要的那件。这是有意的保守策略。
- **不是条码/二维码扫描器。** 遇到印成条码的码，直接用手机自带"相机"扫更快。
- **不联网**：没有云端纠错，也没有历史记录；换手机标签不会同步。
- 需要 iOS 17 及以上。

## 六、这个测试包会过期

当前装在手机上的版本是**开发签名**（有效期到 **2026-11-03**）。到期后 App 打不开，
重新构建安装一次即可；想让别人也能长期用，需要付费开发者账号走 TestFlight（见 `docs/BUILD.md` 未覆盖，问开发方）。

## 七、出问题怎么反馈

直接说现象就够，例如：「明明是那件却一直没标」「把 2073 标成了 2078」「刚打开就说这层没有」。
对应的开关在哪几个文件里写着，见 `docs/BUILD.md §6 现场调参对照表`。
如果方便，**截一张失败时的画面**（相机页 + 标签条都在屏上）最有价值。
